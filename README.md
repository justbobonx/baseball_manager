# Baseball Manager

Plain JavaScript (global scripts, no build step) + PocketBase Cloud baseball team manager.

Docs:
- `abilities-and-generator.md` — the five abilities, grades, handedness and the player generator.
- `play-resolution.md` — how a plate appearance is resolved.
- `dev.md` — PocketBase setup, auth model, collections, repo layout and open items.
- `tables/*.md` — one page per PocketBase collection.

Run: serve the folder statically (or GitHub Pages), open `index.html`, paste the PocketBase URL in Settings.
